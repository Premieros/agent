# AGENT — خدمة العملاء متعددة المشاريع

نظام دعم ذكي لإدارة مشاريع متعددة، قاعدة معرفة منفصلة لكل مشروع، وتجربة الإجابات المستندة إلى تلك المعرفة، ومحادثات الدعم المرتبطة بالمشاريع.

## الصفحات
- `/support`: إدارة المشاريع وملفات المعرفة والتعليمات واختبار الرد.
- `/support/conversations`: محادثات الدعم وتدخل الموظفين.
- `/crm` و`/crm/inbox`: CRM والمتابعات الداخلية القديمة (لم تُمس بياناتها).
- `/support/customer`: تجربة واجهة محادثة الزائر.

## التشغيل
`npm install` ثم `npm test` و`npm run typecheck` و`npm run build`، و`npm run dev` للتطوير.

## قاعدة البيانات
الترحيلات `20261103_support_ai_multproject.sql` و`20261103_support_public_limits.sql` إضافية؛ **لا تشغّلها على قاعدة الإنتاج تلقائيًا**. افحص قاعدة staging وRLS وعزل المشاريع قبل تطبيقها.

## احتياطات التشغيل
ملفات المعرفة في هذه النسخة مخزنة كنصوص؛ رفع PDF/DOCX وتحويلها إلى نص أو vector RAG لم يكتمل. التحقق من الملف وعزو الإجابة إلى المصادر ضروريان. التكاملات الخارجية وواجهة الويب العامة خلف إعدادات البيئة ولا ينبغي تفعيلها قبل اختبار صلاحيات الجلسات ومعدلات الطلبات.

راجع [تفاصيل Support AI](docs/SUPPORT_AI_SETUP.md) و[قنوات الدعم](docs/SUPPORT_CHANNELS.md).

# AGENT — خدمة العملاء

نسخة مركزة على **إدارة علاقات العملاء وخدمة العملاء** دون أدوات تطوير البرامج أو حملات التسويق أو تجارب تنفيذ الكود.

## الوظائف
- `/crm`: العملاء، بيانات الاتصال، المراحل والمتابعات.
- `/crm/inbox`: المحادثات الداخلية، الملاحظات، تسليم المحادثات ومهام المتابعة.
- `/api/assistant/reply-rule`: تهيئة قاعدة بدء الرد الآلي (إعداد فقط؛ الربط الخارجي غير مفعل).

## التشغيل
1. ثبّت Node.js 22 وشغّل `npm install`.
2. اضبط `NEXT_PUBLIC_SUPABASE_URL` و`NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` في البيئة.
3. شغّل `npm run dev`، ثم افتح `/crm`.
4. تحقق عبر `npm test` و`npm run typecheck` و`npm run build`.

## البيانات والحدود
- يعتمد هذا التطبيق على جداول `organizations` و`organization_members` و`leads` و`conversations` و`messages` و`handoff_tasks` ودوال المحادثات الداخلية، وسياسات RLS.
- **لم تُمس بيانات Supabase الفعلية.** أبقينا ملفات migrations التاريخية في المستودع حتى لا تتلف سلسلة الترحيلات؛ قد تشمل بنى قديمة لمزايا محذوفة من واجهة التطبيق. لا تطبّق migrations تاريخية على قاعدة قائمة دون مراجعة حالتها.
- القنوات الخارجية WhatsApp/Messenger/Facebook غير متصلة تلقائيًا؛ المحادثات الحالية داخلية حتى ربط موفر معتمد.
- لا توجد حاليًا واجهة تطوير برمجيات أو Work Sandbox أو GitHub Actions لتنفيذ كود المستخدم.

## نطاق التنظيف
حُذفت صفحات المساعد العام والاستوديو والتسويق، وخدمات البحث والبرمجة وتجارب Sandbox، ومكونات العرض التجريبي، واختباراتها المرتبطة. احتفظنا بمكونات العملاء والمحادثات والمصادقة وقاعدة الرد المساعدة.

> راجع تغييرات هذا الفرع واختبره في بيئة معاينة قبل دمجه إلى `main`.
